# Observed compiler overlap supplement

The new wrapper preserves the stage-1 load command and profile: `nice -n 10 timeout 90s go build -p 2 -a -o <fresh-private-path>/compiler cmd/compile`, `GOMAXPROCS=2`, a fresh cache, a two-second lead, 160 requests, concurrency two, a 180-second profile bound, and a 50 ms request delay. It refuses reused labels/caches and existing output receipts. It never addresses a user service or signals a process it did not create.

`profile_under_build_observed.py` adds a 50 ms process observer and records the profile subprocess start/end. The last observed-alive timestamp is a lower bound on compiler lifetime; the first observed-exit timestamp is an upper bound. The two clocks are recorded. A completion observation after the profile alone is **not** sufficient to prove continuous overlap. A positive verdict requires a witnessed live process after the whole profile subprocess finished. A first observed exit before it finished disproves complete overlap; an observation interval spanning that boundary is reported as unknown.

Use this wrapper beside the exact original `profile.py`. Choose a new label and output filename. The wrapper does not rerun or change the historical baseline. Its default private endpoint is port 7210; supply the verified process PID, token-file path and the same workspace ID as the baseline. Credentials are read by the unchanged profile client and are never included in these receipts.

Use `performance_compare_observed.py` with the same six input arguments and exclusive output argument as `performance_compare.py`. This is a separately staged version so the original frozen comparison source and its manifest remain intact. It verifies the observed overlap classification against the monotonic witnesses and profile receipt interval. It reports the legacy baseline overlap as unavailable. A valid candidate with observed incomplete overlap cannot pass the loaded numeric gate. Unknown baseline overlap is retained as a stated limitation rather than fabricated evidence of a matched continuously loaded experiment.

Offline checks cover alive lower bounds, exit upper bounds, the ambiguous interval, falsified overlap claims, clock interval enclosure, and the original comparator's metric guard suite. These tests are harness checks only; they are not a compiler-load or candidate-performance result.
